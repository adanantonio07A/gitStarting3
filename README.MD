# Taller: Introducción a control de versiones mediante Git

Este repositorio sirve como guía y material de práctica para el taller introductorio de Git. Aquí aplicaremos los conceptos básicos sobre el flujo de trabajo, repositorios locales y la integración con GitHub.

## 🛠️ Requisitos Previos
- [Git](https://git-scm.com/download) instalado en tu equipo (Windows, Linux/Unix o macOS).
- Un editor de texto en consola configurado (ej. Nano, Vim).
- Una cuenta activa en [GitHub](https://github.com/).

## 💻 Comandos Básicos (Cheat Sheet)
Durante este taller, exploraremos el siguiente flujo de trabajo:
